# 逐词同步验收

先完成实际文稿与时间轴，再固定抽样；中途修改英文或时间会使旧标注失效。

- 分层抽样默认48词，覆盖片头、片中、片尾、章节及换人边界，并追加全部零时长、重叠等挑战项。固定抽样不能用挑选容易词替代。
- 每个样本保存原音片段、波形、当前边界和可选独立CTC测量。人工页面默认隐藏系统与CTC边界，先听音并标注，再比较。
- 人工目标：至少40个独立计时单词，固定样本需全部完成标注；至少95%的词起点和终点均在200ms内，且无持续漂移。未听辨的记录保留空值，不计作通过。
- CTC路径分、ASR置信度与两个模型一致性都是自动证据，不能称为人工准确率。数字与代码没有明确口语稿时不猜发音。
- 比较候选文稿时使用原始声学概率，不把wildcard归一化分数当作候选质量；强制对齐得到正时长本身不证明实际发音。

在项目目录运行 `.venv\Scripts\python.exe scripts\audit-sync.py --help` 查看准备、CTC审查、人工记录及汇总入口。该工具只输出本机验收文件，真实课程原声、标注和模型权重不进入源码或发布包。

整课自动重测可运行 `.venv\Scripts\python.exe scripts\remeasure-sync.py --episode <episode.json> --audio <audio.mp3> --output <独立草案目录>`。该入口复用本机已缓存的CTC权重，在交叠窗口内测量，并要求无提示文本支持、双窗边界稳定且不产生新的邻词重叠。它输出草案和证据，不覆盖课程或改写接口配置。

声学缓存按音频、模型、算法和窗口生成指纹，缓存内容另校验哈希。改动词边界会更新句子、字幕页、卡片和主题目录时间，并使旧视频及旧同步标注失效。文稿改动还须更新受影响的中文教学内容。

如果某声学模型已参与时间修正，再用它对照同一时间轴只属于一致性排查；其结果不能充当独立精度证明。真人先听音、再标边界，无法确定的数字、代码、重复词保留为不确定，不计算成通过。
