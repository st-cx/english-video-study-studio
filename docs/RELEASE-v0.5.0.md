# v0.5.0 发布说明

本版改进长课原声核对、简体中文教学恢复和学习包隐私。**人工单词边界标注仍为0，尚未达到“95%边界误差不超过200ms”的同步验收目标。** 这份说明不表示整个用户目标已经完成。

## 本版改进

- 原声识别与强制对齐复用同一个已加载模型；优先本机可用GPU，CPU回退如实记录实际模型及计算类型。
- 分段识别的诊断统一到整片时间。争议依据原文和时段唯一定位，实际测量才能修复；不均分时长，不凭模型置信分清旗。
- 增加独立CTC对照、固定单词抽样和人工听辨入口。多词整体高亮单位不会被当成一个独立单词混算精度。
- 中文统一为简体；必需译文或语境词义失败仍停止。可选卡片和搭配经过有界修复仍无效时省略并留记录，不编造标题和原句出处。
- 原模型多轮复核未收敛时保留原记录，编辑复核另行保存。并行排版使用独立临时文件，减少缓存和输出互相覆盖。
- 可携带学习页面、来源元数据与笔记清理URL账号密码及敏感token/key/签名参数，保留视频ID等必要公开参数。私有下载输入继续使用原URL。

## 本轮真实制作状态

优化前已完成本机源码、私有运行资料和课程媒体备份并校验哈希。MIT 43:05.964课程已合并9章中文，共537句、6,722个计时单位、364张讲解卡、817个短语和616字幕页；译文与词义均已覆盖。第4、5、8章另做完整中文编辑审阅，原模型needs_review记录没有被改成通过。

课程仍保留37项参考稿差异、19条对齐争议和1个零时长，各章保持来源检查状态。它们可能重叠；中文内容齐全不代表原声及时间边界全部正确，也未据此强行导出整片成片。

an及邻词按证据联合修正后，同一固定51词样本重新测量：50词可做CTC对照，27/50词的双边界最大模型差不超过200ms，23/50词超出；1个数字因无明确读法保持未测。这是模型差异，不是人工正确率。人工标注仍为0；修正前26/50只保留为历史快照。
