# v0.6.2 官网投稿与本地稿件登记

工作室可以在通过检查的精听草稿中登记官网稿件的 BV 号。登记需要明确确认已在本人创作中心核对这份成片；本机重新检查课程版本、视频凭据、封面和发布权限后，原子保存稿件号、官网提交渠道和用户确认来源，关闭自动投稿，防止重复发布。

已有提交、结果不明或正在上传的记录不能被覆盖；同一稿件号不能登记到不同草稿，同一记录重复登记相同编号保持幂等。官网登记不代表本机直接投稿接口已连通，也不把平台接收稿件等同于审核通过。

本轮实际验证及平台提交状态见 [验收记录](VALIDATION.md)。本机既有模型、课程、学习进度与收藏继续沿用，真实账号资料、媒体与回执证据不进入开源包。
