# v0.6.1 减少回听负担与核验真实投稿链路

长课的待检查记录继续按原声证据复核。本轮自动处理原先33条记录中的6条；剩22项文稿差异、5条边界争议，合并为23段、约100.8秒原声。记录可能指向同一问题，不把6条记录称为6个独立错误。确需听辨的内容保留一键回听、循环、变速及判断保存入口；另加明确的暂停／继续按钮，便于停下比较候选。

实际修订包括 `statement`、`console` 的边界，修正幅度分别约2.45秒、4.74秒；删除重复的 `language`，保留旧词句编号别名。受影响的句子、字幕、词义及讲解由修订稿重建。当前长课包含6722个计时单位、535句、365张讲解卡、614页字幕和17个主题；严格画面检查1281场景、8301项检查通过。固定50词人工听辨仍为0/50，不能宣称“95%边界误差不超过200ms”已验收。

从 Creative Commons 官方频道实际获取了 [Wanna Work Together?](https://www.youtube.com/watch?v=q0VzUigrb_g)，选用原片6.5–33.55秒、共27.05秒的完整口语片段，经过常规制作管线得到65词、4句、4张卡，自动质量检查无标记。随后对48个分层样本作双裁切CTC诊断，再补充5个交叠窗口，按原有声学门槛修正15个可靠词边界，保留65词原文字和编号；低分模型结果不强行改时，也不充当人工精度验收。[官方作品页](https://creativecommons.org/about/videos/wanna-work-together/)明确采用 [CC BY 2.5](https://creativecommons.org/licenses/by/2.5/)，发布时须注明原作标题、作者、来源、许可及节选和教学改编。真实媒体和课程不随开源包分发。

这次真实素材运行暴露并修复了两类问题：YouTube WebVTT 将上一行短暂重复显示时，依据原始行、行内时间及相邻短暂显示记录移除显示残留，保留真正重复的对白；长音乐段后的零时长对齐不能再借用远处同词的时间，缺少就近语音锚点时保留待检查。通过时间非零或文稿相同不能替代实际发音证据。

每次导出新增与MP4同目录的版本凭据，绑定影响画面的教学内容、原音、原画面、封面、成片文件、时间范围、尺寸和帧率。渲染组件、布局算法、字体度量、CSS及相关依赖也纳入独立指纹；审核记录、应用版本和无关工作室改动不会让成片误过期。渲染期间输入改变则停止发布；视频、凭据、学习页及课程数据共同替换，失败恢复原版本。没有凭据或与当前课程不符的旧成片不能投稿。

扫码流程兼容当前官方账号域名，二维码在内存生成，生成与状态查询防缓存；成功响应中的刷新字段允许缺省，保留正确Cookie编码。工作室与独立实时页共用同一扫码界面和有效会话，过期自动换码；后台持续接收手机确认，不依赖网页是否在前台。旧轮询响应不会覆盖新码，已成功的登录不会因二维码寿命结束再次误报过期；有旧登录信息时重新扫码也不会被误判完成。安全诊断保留最近12次状态变化及失败阶段，不记录登录链接或凭据。

B站工作区新增显式登录状态验证、上传分块及封面进度，并区分“仅上传媒体”和“已提交稿件”。到实际提交边界前持久化记录；提交后结果不明时禁止自动重投。可只读查询近期稿件，将稿件编号、上传分段或同名标题的匹配显示为候选；同名候选与暂未找到都不能授权重复提交。转载稿关闭禁止转载标记，仍需用户拥有素材发布权利。明确开启的单条草稿可等待扫码，真实后台每分钟检查并派发；未连接不转为失败，也不会自动弹出二维码。工作区可随时暂停尚未开始的自动投稿，提交前再次核对授权，避免暂停时的旧快照继续发布。

本轮修改前完成746文件、222596142字节私有备份。现有模型连接、课程编号及浏览器学习存储键继续沿用；私有配置、密钥、任务、原音证据与学习标注不进入源码和发布附件。
