## 本项目可以建立的差异

本项目定位是“从原声证据出发的精听制作工作室”：一份课程数据同时服务个人精听、人工复核和教学视频制作。

1. **减少人工判断次数。** 将同一原音区间的文稿差异和时间边界争议关联，提供候选与一键回听。自动决定必须保存证据和理由；用户只处理剩余的不确定内容。衡量原始记录数、独立待听辨片段数及实际确认次数，不用“模型同意”替代人耳验收。
2. **修订可以追溯。** 区分参考字幕、无提示识别、对齐器与人工确认；修订影响到的字幕页、译文、词卡和视频版本一起更新。模型参与修正后，不能再将同一模型的边界差值当作独立准确率。
3. **学习与成品共享时间轴。** 本地交互页、逐词字幕、学习笔记、主题章节和投稿成品使用同一份课程数据。播放、跳转和变速都从原音时间计算。
4. **资源到发布保持状态连续。** 订阅发现、手动／自动制作、待检查、成片、投稿草稿、提交结果分别记录。修改过的课程不能混用旧成片；结果不明的提交先核对平台记录，不能盲目重投。

前两项的可靠性必须通过真实修订记录和听辨验收证明；后两项必须通过真实交互与端到端运行证明。设计目标不是已经完成的验收结果。未来可按真实回听和收藏记录生成短复习清单，不将“看完”直接判定为“掌握”。

## 资源获取的边界

资源入口包括本地音视频、公开页面、直链音视频、RSS／播客和公开播放列表。具体可获取性由素材来源、网络及下载器当前支持情况决定，不能承诺所有视频、字幕和画质都可获取。

[yt-dlp 官方说明](https://github.com/yt-dlp/yt-dlp)提供字幕、播放列表、归档去重和部分许可元数据能力。[官方 EJS 文档](https://github.com/yt-dlp/yt-dlp/wiki/EJS)明确完整 YouTube 支持需要外部 JavaScript 运行时及匹配的 EJS 组件；Node 需要显式启用。能读取某个视频的标题，不等于其视频文件或字幕下载已通过验证。

原始来源 URL、作者及许可／授权依据应随课程保存。下载和个人精听不自动等于获得公开发布权利。

## B站投稿的实查结果

旧的 [Nemo2011/bilibili-api](https://github.com/Nemo2011/bilibili-api) 仓库已于 2026-07-06 归档，当前只保留停止维护声明。不能直接依据历史教程承诺旧版扫码及上传接口持续可用。

[B站官方开放平台](https://openhome.bilibili.com/doc)提供视频稿件发布、查询等能力。[官方 OAuth 文档](https://open.bilibili.com/doc/4/eaf0e2b5-bde9-b9a0-9be1-019bb455701c)要求入驻、创建应用、申请权限并取得用户授权；这与普通 B站网页登录状态是两件事。

官方投稿流程为预处理、分片上传、合片、封面和稿件提交；见[上传预处理](https://open.bilibili.com/doc/4/0c532c6a-e6fb-0aff-8021-905ae2409095)、[分片上传](https://open.bilibili.com/doc/4/733a520a-c50f-7bb4-17cb-35338ba20500)、[签名规范](https://open.bilibili.com/doc/4/8673959e-f7bb-56e6-6e68-d225f971b81b)及[官方演示仓库](https://github.com/bilibili-openplatform/demo)。接口调用成功和稿件最终通过平台审核也需要分别显示。

工具应明确区分“投稿草稿已准备”“本机已保存登录信息”“已发起提交”“取得稿件编号”“平台最终审核状态”。未经过真实账号提交的连接不能标记为已验证。直接投稿不可用时，提供包含精听成片、封面、标题、简介和来源的投稿包，并打开[官方创作中心](https://member.bilibili.com/platform/upload/video/frame)。

[B站官方内容标识公告](https://www.bilibili.com/opus/840812291428450327)要求转载选择转载并添加来源；添加字幕不能自动判定为自制或已获得授权。投稿类型、来源和发布权利应由用户按实际素材确认。该要求只影响公开发布，不能将原来的模型连接、进度和收藏重置。

## 发布验收应记录什么

- 在同一原课上证明修订后播放、跳转、循环和同步工作，保留原配置、进度与收藏。
- 列明自动解决、仍不确定、用户已确认的数量；逐词人耳准确率单独计算。
- 订阅首次只处理来源列表首条，重复检查不重复建任务；自动制作和投稿均需明确启用。
- 缺少成片、存在质量问题、课程已变化、权利未确认时阻止投稿，并显示具体原因。
- 远端提交结果不明时保留状态，先去创作中心核对，避免重复投稿。
- 开源内容排除账号凭据、模型密钥、本地学习数据及没有公开发布许可的素材。
